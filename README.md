# AI-Powered Intelligent Resume & Job Application Assistant

A full-stack AI application that helps job seekers optimize resumes, generate tailored cover letters, and prepare for interviews using modern LLM APIs.

Built with **FastAPI**, **OpenAI API**, and a clean **HTML/CSS/JavaScript frontend**.

---

## 🚀 Features

- ✅ Resume optimization based on job descriptions (ATS-friendly)
- ✅ AI-generated professional cover letters
- ✅ Interview preparation with role-specific questions
- ✅ Clean, responsive frontend UI
- ✅ FastAPI backend with REST endpoints
- ✅ Environment-variable based API key security

---

## 🛠 Tech Stack

| Layer       | Technology |
|------------|------------|
| Backend     | FastAPI (Python) |
| AI Model    | OpenAI API (Responses API) |
| Frontend    | HTML, CSS, JavaScript |
| Server      | Uvicorn |
| Config      | python-dotenv |
